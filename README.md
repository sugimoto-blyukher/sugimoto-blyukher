# Hi, I'm Shintaro 👋

**Computer Architecture · Operating Systems · Embedded Systems**

I'm a computer science undergraduate at **Future University Hakodate**, Japan.

I'm interested in how computers work close to the hardware, especially **RISC-V**, **processor architecture**, and **systems software**.

## 🔍 What I'm working on

- **RISC-V & CPU design** — learning digital logic and processor design with Verilog and FPGA boards.
- **Operating systems** — experimenting with a 32-bit RISC-V kernel on QEMU.
- **Backend development** — building APIs with Go and learning API design and testing.
