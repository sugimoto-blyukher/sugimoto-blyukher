# こんにちは、Shintaroです 👋

[English](README.md) | **日本語**

**コンピュータアーキテクチャ・オペレーティングシステム・組み込みシステム**

公立はこだて未来大学で情報科学を学んでいる学部生です。

コンピュータのハードウェアに近い領域に関心があり、特に**RISC-V、プロセッサアーキテクチャ、システムソフトウェア**に興味があります。

## 🔍 現在取り組んでいること

- **RISC-V・CPU設計** — VerilogとFPGAを用いた論理回路およびプロセッサ設計の学習。
- **バックエンド開発** — Goを用いたAPI開発、API設計およびテストの学習。
